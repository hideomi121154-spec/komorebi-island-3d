# 🌿 こもれび島 3D — Komorebi Island

オリジナルの3Dスローライフゲーム。小さな島を歩き、採集・釣り・農業・住民との会話・商店での売買・家の改築を楽しむ、スマホ対応のWeb試作品です。

## プレイ

公開済みの **GitHub Pages** で、次のURLから遊べます。

https://hideomi121154-spec.github.io/komorebi-island-3d/

## 操作

- iPhone・Android：画面の十字キーで移動し、「調べる」を押す。カメラ回転ボタンも使用可能。
- PC：WASD／矢印キーで移動、E／Spaceで調べる。
- 釣り：池で「釣りをする」を選択し、**島の3D画面のまま**竿を投げて、浮きが沈んだらタイミングよく引き上げる。
- セーブ：同じブラウザのlocalStorageに保存。公開先URLの変更やSafariのデータ削除で失う可能性があるので、ゲーム内のJSONバックアップも利用してください。

## 3Dの建物に入る（v0.4）

- 家と商店の**正面玄関**に近づき「家に入る」「お店に入る」を押すと、短いドア移動演出を経て室内の3Dシーンに入る。
- 室内も同じゲーム画面のまま十字キーで移動し、対象に近づいて「調べる」。
- **家**：ベッドで眠って翌日へ、収納棚で服の色を変える、作業テーブルで増築する。
- **商店**：店員と会話して購入・買取、店内の棚から直接商品を選ぶ。
- 出入口に戻って「島に出る」を押すと屋外に戻る。
- 会話・売買は画面下の小さなパネルで表示し、背後に3Dの部屋が見える。
- 屋内の位置は一時的な状態。保存ファイルでは屋外の座標が保持され、ゲーム再開は屋外から行う。

## キャラクターの吹き出し会話（v0.5）

- 商店で店員に話しかけると、**3Dキャラクターの頭上に会話の吹き出し**が表示されます。画面下には小さな「買い物・買取・やめる」の選択肢が出ます。
- 購入／買取を選んだときだけ、従来の操作しやすい商品一覧パネルに切り替わります。戻ると再び吹き出し会話になります。
- 島にいる住民ミミとの会話も、頭上の吹き出しで行えます。プレゼントは従来どおり1日1回です。
- 吹き出しの表示位置はカメラの投影行列から計算します。PC・スマホ／WebGL・代替2D投影の両方で利用できます。

## 3D畑の水やり（v0.6）

- 畑で種をまき、もう一度近づいて「💧 水をあげる」を押すと、**その3D島の画面のまま**ジョウロから水滴が流れ、水しぶきが畑に落ちる演出が始まります。
- 水をあげた畑の土は当日濡れた色になり、初回の水やりで収穫までの日数が**2日から1日に短縮**されます。
- 同じ畑の水やりは1日に1回。育ち切ったら「収穫する」でにんじんを取れます。水をあげなくても従来どおり2日で育ちます。
- 旧セーブデータと互換です。新しい画像素材や外部ライブラリは不要です。

## 日本の実時刻に同期した昼夜（v0.8）

**日本標準時（JST）の現在時刻に合わせて**、島の景色が朝・昼・夕方・夜へ変化します。朝は明るい空、夕方は夕焼け、夜は月と星が見える空です。室内は夜でも見やすい明るさです。

- 左上の時計はスマホの時刻と同じJSTです。**現実の1分＝ゲームの1分**で、早送りはしません。
- 時計は現在時刻を表示するだけで、タップして時間を飛ばすことはできません。
- 日本時間の0:00に自動で翌日となり、木の実や貝がらが復活し、畑も日付に応じて育ちます。
- スマホでゲームを閉じていた時間も日付として経過し、次回起動時に経過日数を反映します。
- 「翌日へ」は廃止して「💾 セーブ」に変更。家のベッドでも休憩・セーブできますが、翌日へ早送りはしません。
- 以前のセーブデータはそのまま利用でき、**初回移行では現在の日付を登録するだけ**なので所持金・在庫・日数は維持されます。
- 端末時計を参照するため、スマホの時刻設定が正しいことが前提です。東京時間（Asia/Tokyo）で表示します。

## 🌿 オリジナル住民「モコ」（v0.9）

小さくて白い、頭に葉っぱの芽が生えた**オリジナルの島の生き物「モコ」**が仲間入りしました。既存作品のキャラクター・モデル・画像・音声を流用していません。

- **日中**：島の広場を、立ち止まりながらちょこちょこ散歩します。
- **夜**：家の近くで眠そうに過ごします。日本時間の昼夜に連動します。
- **会話**：近くで「話しかける」を押すと、モコが立ち止まり、頭上に吹き出しが出ます。「もっとおはなし」で別のセリフも聞けます。
- **プレゼント**：**1日1回、木の実1個**をくれます。ミミの種プレゼントとは別に管理します。
- 3Dモデル・移動・会話は `moko3d.js` で制御し、従来の島のセーブデータを引き継げます。


## 🗺️ 島の拡張（v1.0）

島の草地を旧 `13.45 × 11.20` から `20.7 × 16.65` に拡大（面積は約2.3倍）。旧セーブ・家・商店・釣り・畑・住民・実時間の昼夜は維持します。

- **新しい景観**：小川と滝・木の橋・スイレンの池・キャンプ場・海辺の桟橋と小舟・森のコテージ
- **新しい資源**：外側に木18本（既存の木の採集データ番号は変更せず末尾に追加）、貝がら3か所
- **新しい散策路**：中心部から森・キャンプ場・コテージ・橋・桟橋へ接続
- **島マップ**：右側の「🗺」ボタンで開き、赤い点で現在地を確認。画面上は3Dカメラがプレイヤーを追従するため、広くなった外周は歩いて探索します
- **コテージ**：正面玄関から3Dで入室。現段階では既存の家の室内モデルを共用（独立した室内や住人は後日拡張）
- **地形の当たり判定**：海岸線・コテージ・池・小川に対応。小川は橋の部分から横断可能

`expansion3d.js` で新しい地形の装飾・地図を独立管理し、既存の `game.js` の採集や室内処理を再利用。 `node --test tests/expansion.test.mjs` で新しい地形・描画ルーチンの単体テストを実行できます。

**動作上の注意**：GitHubのコード反映とWeb公開の反映タイミングは異なります。GitHub Actionsのデプロイ状況とiPhone Safariでの移動・地図・コテージ出入りは別途実機で確認が必要です。

## 🏗️ 島の再開発・高層マンション建設（v1.1）

島の中心を大きく占有しないように、**高層マンションの工事現場を島の右奥（東側）に配置**。中央の家・商店・ミミ・モコ・森・池・畑・桟橋は引き続き利用できます。

- **見た目**：建設中のRC躯体、青い足場ネット、安全柵、建設資材、バックホー、ヘルメットの作業員、タワークレーンをすべてローポリの3Dメッシュで生成。吊り荷が上下・横移動し、重機のアームと作業員も動きます。
- **カメラ**：初回表示では島の中心と右奥の再開発地区が見える引きの視点。右側の「🏗️」ボタンで街を見渡すカメラと普段の追従カメラを切り替えます。十字キーで移動し始めると従来の追従カメラへ戻ります。
- **工事進捗**：初期32%。実際の日本時間の日付が1日進むごとに2%前進。現場の案内を調べる、または画面の進捗バーをタップすると詳細を開き、木材2個を納品して8%進められます。
- **建設完了**：100%になると9階建てマンションが完成し、作業員・クレーン・資材が撤去されます。完成後も建物は島に残ります。
- **道と安全**：中心の街と工事地区をアクセス道路でつなぎ、工事エリアは安全柵で通行不可にします。旧セーブの木の採集番号は保持したまま、区画に重なる木だけ別の場所に移します。
- **保存**：従来のセーブキーとバージョン1を引き継ぎ、`redevelopmentProgress` と `redevelopmentDateKey` を追加。すでに遊んでいる人は初めてこのバージョンを起動した日から工事日数を数えます。

コードは外部ライブラリなしの `redevelopment3d.js` に分離。建物・工事現場の描画は WebGL と Canvas2D の双方に対応し、`tests/redevelopment.test.mjs` で配置・進捗・ジオメトリの整合性を検証します。実機のSafariでのフレームレートは別途検証が必要です。

## 開発

外部JavaScriptライブラリなしで、HTML + CSS + JavaScript（WebGL1）を使用。WebGLが使えない環境向けにCanvas2D投影表示も用意しています。

```sh
python3 -m http.server 8000
# http://localhost:8000
```

```sh
node --check game.js
node --test tests/*.test.mjs
```
